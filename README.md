# go-workspace

A collection of Go learning exercises, examples, and small tools.

## Directories

- **assertions**: Provides assertion helpers for testing (e.g., `AssertStringGotWant`).
- **cli**: A command-line interface tool with subcommands (binary2dec, multiserve, serve, version).
- **cmdChroma**: A collection of command-line tools and servers (chat-server, chroma syntax highlighter, mcp-server).
- **debugFormat**: Utilities for debugging output (e.g., `debugWriter` package).
- **l**: A collection of Go learning examples covering topics like arrays, slices, concurrency, etc.
- **docs**: Documentation (including superpowers specifications).
